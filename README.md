# Vaishnavi Khairnar — Portfolio

A modern, responsive portfolio website crafted with React, TypeScript, and Vite.

## 🚀 Features

- **Interactive 3D ID Badge**: Custom interactive realistic badge with 3D effects, charms, and stamps.
- **Projects Showcase**: Case studies with quantified metrics, live links, and tech stacks.
- **Skills & Stack**: Interactive interactive skill tags and proficiency cards.
- **Responsive Design**: Optimized across mobile, tablet, laptop, and ultra-wide viewports.
- **Performance**: Instant loading with GPU-accelerated micro-animations.

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite
- **Language**: TypeScript
- **Styling**: Modern Vanilla CSS (tokens, variables, responsive breakpoints)
- **Icons**: Lucide Icons

## 💻 Local Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
